# Crystal jamoa kelishuvi

Crystal jamoasi logistika va kuryer xizmatini ishlab chiqadi. Birinchi namoyishda buyurtmani ochish, omborga qabul qilish, kuryerga biriktirish va topshirishni kuzatish mumkin.

| Rol | Mas’uliyat |
| --- | --- |
| Tech Lead | Repo, kirishlar, main himoyasi va yakuniy merge |
| Product Owner / Scrum Master | Issue, ustuvorlik, loyiha doskasi va stand-up |
| QA & Code Review Lead | Testlar, tekshiruv ro‘yxati va aniq PR izohlari |
| DevOps / Platform Engineer | Ishga tushadigan ilova, README va keyingi infratuzilma |
| Technical Writer & Security Champion | Hujjatlar, kirishlar yozuvi va sirlarni tekshirish |

Jamoa a’zosi vazifani issue orqali oladi, alohida branchda bajaradi va PR ochadi. Boshqa a’zo tekshiradi. Tech Lead tasdiq va tekshiruv natijalarini ko‘rgach merge qiladi. Jamoa 10 daqiqalik stand-upda bajarilgan ish, keyingi vazifa va to‘siqlarni muhokama qiladi.
